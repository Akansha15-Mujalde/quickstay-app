#  QuickStay App

A premium, full-stack hotel booking and property management application built using the modern **MERN Stack** (MongoDB, Express, React, Node.js). This platform offers a seamless user experience with high-end aesthetics, tailored for lightning-fast accommodation searches and booking management.

---

##  Features

* **Modern Midnight UI Dashboard**: Designed with a sophisticated dark-themed, glassmorphic aesthetic and bold, professional typography.
* **Dynamic Room Display Cards**: High-performance frontend grids showcase real-time room availability, amenities, and pricing.
* **Seamless Booking Flow**: An optimized booking engine that guides users from discovery to successful reservation in seconds.
* **Robust Backend Architecture**: Fully functional Express REST APIs paired with a secure MongoDB database schema.

---

##  Tech Stack

* **Frontend**: React.js, Vite, Tailwind CSS (Custom UI/UX Theme)
* **Backend**: Node.js, Express.js
* **Database**: MongoDB
